# Harini's Little Space

A gentle, responsive React + Vite cycle companion designed as a private little space for Harini.

## Run locally

```bash
npm install
npm run dev
```

## Included

- Cycle day and phase estimate
- Next-period estimate
- Mood check-in
- Symptom tags
- Cycle settings
- Light / dark theme
- Local-only browser persistence

This is a wellness companion, not a medical diagnosis or substitute for medical care.
